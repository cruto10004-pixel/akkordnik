# 🎸 Аккордник

Песенник с аккордами для гитары: тексты с аккордами над словами или сверху, транспонирование, каподастр, схемы и фото аккордов, импорт песен с сайтов (AmDm.ru, akkords.pro и др.), темы оформления.

## Установка на Android

1. Откройте [последний релиз](../../releases/latest) на телефоне.
2. Скачайте `akkordnik.apk` и откройте его. Если Android спросит — разрешите установку из этого источника.

Новая версия собирается автоматически при каждом изменении в ветке `main` (вкладка **Actions**). Обновление ставится поверх старого, песни сохраняются.

## Импорт песен

- В приложении: **Импорт** → вставьте ссылку на страницу песни.
- Из браузера: **Поделиться → Аккордник** на странице с песней.

## Структура

- `android/` — нативное Android-приложение: Kotlin + Jetpack Compose (Material 3), без WebView.
  - `app/src/main/java/ru/akkordnik/app/music/` — разбор аккордов, транспонирование, аппликатуры, парсер песен с сайтов (Jsoup).
  - `app/src/main/java/ru/akkordnik/app/data/` — модель и хранилище (JSON-файл, формат совместим с резервной копией).
  - `app/src/main/java/ru/akkordnik/app/ui/` — экраны, темы, анимации.
  - `app/src/test/` — тесты парсера (сверка с эталоном) и скриншот-тесты Robolectric.
- `www/index.html` — прежняя веб-версия (для справки; данные из неё переносятся автоматически при первом запуске).
- `.github/workflows/android.yml` — тесты и сборка APK.

## Сборка локально

```bash
cd android
./gradlew testDebugUnitTest --tests 'ru.akkordnik.app.ParseTest'
./gradlew assembleDebug
```

## Подпись

Релизная сборка подписывается ключом из секретов репозитория `KEYSTORE_B64` и `KEYSTORE_PASSWORD`. Без них собирается debug-версия. Храните копию ключа — без него нельзя выпустить обновление, которое встанет поверх.
